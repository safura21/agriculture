# 🌾 Agriculture Rainfall Dashboard

This project is an **Agriculture Rainfall Analysis Dashboard** created using **Power BI**.

### 🛠️ Tools Used

* Power BI
* Power Query
* Data Visualization

### 📊 Analysis

* Year-wise Rainfall
* Season-wise Rainfall
* Crop-wise Rainfall
* Location-wise Rainfall

### 🎯 Objective

To analyze and visualize agricultural rainfall data using an interactive Power BI dashboard.
